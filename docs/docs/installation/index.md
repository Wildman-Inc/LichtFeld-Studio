# Installation

Release archives for this unofficial fork, when published, appear on the [Wildman-Inc/LichtFeld-Studio release page](https://github.com/Wildman-Inc/LichtFeld-Studio/releases). The source-build instructions remain authoritative when no matching archive is available.

The fork publishes **LichtFeld Studio for ROCm** and the separate **LichtFeld Arc Viewer (Experimental)** standalone Vulkan PLY viewer.

LichtFeld Arc Viewer (Experimental) is not a Studio training target and has been validated only on the compatible AMD Vulkan fallback, not on physical Intel Arc hardware.

For fork-specific source builds and platform instructions, see the [fork repository](https://github.com/Wildman-Inc/LichtFeld-Studio), [Windows ROCm and LichtFeld Arc Viewer (Experimental) builds](building/windows-rocm.md), [Linux ROCm and CDNA builds](building/linux-rocm.md), and the repo-local docs in [docs/README.md](../../README.md). General upstream CUDA build notes remain in the [upstream Wiki](https://github.com/MrNeRF/LichtFeld-Studio/wiki/).
